# Meridian Production Demo Storyboard

Silent screen recording of the live production product. Target 30-60 seconds; aim for approximately 45-55 seconds. Open the [production Nansen mode](https://otgos.run.place/?mode=nansen) before recording. No terminal or local service is required.

| Time | Screen and readable on-screen point |
|---|---|
| 0-5 sec | Show OTG Analytics with ANALYTICS and NANSEN visible. Establish the product identity. |
| 5-13 sec | Show Current Market Context: `$GUN` price, 1-hour move, Smart Money flow, and current context. |
| 13-28 sec | Show Historical OTG Reaction. Select Trades, Volume, and Buyers in turn, leaving enough time to read each chart and its 0h / 1h / 6h / 24h horizons. |
| 28-36 sec | Briefly open the Guide to show that interpretation and limitations are available without crowding the main page. |
| 36-46 sec | Return to the chart and Market Takeaway. Keep the conclusion, Data update timestamp, and “Data provided by Nansen” attribution visible. |
| 46-55 sec | End with OTG Analytics and the repository identity or GitHub link, if practical. |

## Capture Rules

- Record the actual production product at the URL above; no terminal or local service is needed.
- Do not manually refresh live data; the product displays the latest shared observation.
- Do not expose credentials, `.env`, browser developer tools, or request headers.
- Do not substitute fixture values or imply they are live.
- Keep visible values readable and do not describe results as causal, predictive, or a trading signal.
- Target a final duration of 30-60 seconds.
