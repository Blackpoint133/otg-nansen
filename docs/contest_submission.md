# Contest submission

Official Nansen Meridian Buildathon pages reviewed on 2026-09-21 state:

- event window: September 14-27, 2026;
- submission close: September 27 at 23:59 UTC;
- requirement: log 1,000 or more Nansen API calls against the build's key;
- public GitHub repository required;
- demo post on X must tag `@nansen_ai` and include the GitHub link;
- screen recording should show the live build and is described as 30-60 seconds;
- entry form requires email, X post URL, and GitHub repository;
- judging criteria are Data Integration, Functionality, Creativity & Originality, and Documentation & Submission, equally weighted.
