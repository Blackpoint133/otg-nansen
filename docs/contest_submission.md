# Contest Submission

Official Nansen Meridian Buildathon materials reviewed for the September 14-27, 2026 event differ on the API-call threshold:

- The [campaign page](https://nansen.ai/campaigns/meridian-buildathon) states 1,000 API calls.
- The [Meridian FAQ](https://release.nansen.ai/help/articles/3540155-nansen-meridian-buildathon-sep-14-27) states 100+ API calls during September 14-27.

The reviewed materials give the deadline as September 27, 2026 at 23:59 UTC. This project does not decide which threshold supersedes the other. Its documented conservative project-side minimum is recorded in the [submission readiness document](meridian_submission.md); it is not represented as confirmation of Nansen's internal quota counter. No synthetic calls were generated.

Other submission materials describe:

- A public GitHub repository.
- An X post tagging `@nansen_ai` and including the GitHub link.
- A screen recording of the live product, specified as 30-60 seconds.
- An entry form requesting email, X post URL, and GitHub repository.
- Four equally weighted judging criteria: Data Integration, Functionality & Workability, Creativity & Originality, and Documentation & Submission.
