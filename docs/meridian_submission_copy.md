## PROJECT_NAME

OTG - Nansen Market Intelligence

## ONE_LINE_DESCRIPTION

A descriptive research demo pairing Avalanche `$GUN` Smart Money data with
Off The Grid marketplace activity.

## SHORT_DESCRIPTION

OTG - Nansen Market Intelligence studies how Avalanche `$GUN` Smart Money
observations relate to Off The Grid marketplace activity. It combines 12,336
canonical hourly observations with a preregistered descriptive relationship
analysis and historical price-shock summaries. A local demo also requests a
current Nansen observation on demand and uses its one-hour return to select
the relevant historical context. The analyzed relationships were weak and
time-inconsistent. The project makes no prediction, causality, or trading
signal claim.

## HOW_NANSEN_IS_USED

Nansen Avalanche `$GUN` Smart Money Flows provide hourly price and flow-count
observations. Historical hourly price returns and flow-imbalance share were
specified as analysis drivers before the committed Task 034 snapshot was
analyzed. The Task 034 result files are the source for the historical panels.
The local demo uses a bounded live Flows request only after the operator
selects Refresh Live Data. Its latest completed hourly return is compared with
the committed historical price-shock thresholds to select positive, negative,
middle-range, or unavailable context. The browser never receives the API key.

## WHAT_WAS_BUILT

The repository contains Nansen ingestion and normalized history, a complete
12,336-hour aligned analytical foundation, committed Task 034 relationship
and event-summary results, and a local judge-facing demo. The demo combines
one explicit live Nansen refresh with historical relationship and price-shock
panels. It uses no database at runtime, caches sanitized live results in
memory, and preserves an honest unavailable state if the request fails.
Research outputs remain descriptive; weak and time-inconsistent findings are
reported without tuning or predictive interpretation.

## KEY_TECHNICAL_FACTS

- 12,336 canonical hourly observations.
- Avalanche `$GUN` Smart Money source data.
- OTG marketplace hourly aggregation in native GUN units.
- Local live Nansen panel with an explicit, bounded refresh.
- Preregistered descriptive relationship analysis.
- Historical price-shock event-response view.
- Descriptive, noncausal, nonpredictive positioning.
