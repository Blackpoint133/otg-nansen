# Meridian Production Demo Recording Checklist

Use the actual production OTG Analytics Nansen mode. Target 30-60 seconds.

## Before Recording

1. Open <https://otgos.run.place/?mode=nansen> in a normal browser.
2. Confirm the live `$GUN` values and current context are visible.
3. Confirm Trades, Volume, and Buyers are available in the left panel.
4. Confirm the Historical OTG Reaction chart is visible.
5. Open Guide once and confirm it works, then close it.
6. Confirm Market Takeaway, Data update, and “Data provided by Nansen” are visible.
7. Close desktop notifications and other unrelated windows.
8. Set browser zoom and window size so the values and chart are readable.
9. Prepare the screen recorder. Do not open developer tools.

## Recording Sequence

| Time | Screen action |
|---|---|
| 0-5 sec | Show OTG Analytics and the NANSEN mode in the analytics navigation. |
| 5-13 sec | Show Current Market Context and its `$GUN` price, 1-hour move, Smart Money flow, and context. |
| 13-28 sec | Show Historical OTG Reaction. Slowly select Trades, Volume, and Buyers so the fixed horizons remain readable. |
| 28-36 sec | Briefly show the Guide and return to the Nansen page. |
| 36-46 sec | Show the chart conclusion, Data update time, and Nansen attribution. |
| 46-55 sec | End on product identity and GitHub link if practical. |

## Recording Rules

- Record the real production product and its displayed live observation.
- Do not show terminals, credentials, `.env`, browser developer tools, or request headers.
- Do not present fixture data as live.
- Do not claim prediction, causality, alpha, or a standalone trading signal.
- Keep the observation and chart text legible.
- Target a duration of 30-60 seconds.

## After Recording

- Confirm the video is 30-60 seconds and the text is readable.
- Confirm the live context, historical chart, takeaway, update time, and attribution appear.
- Review the video before posting or submitting it.
