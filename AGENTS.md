# Agent guidance

- This public repository supports Nansen-powered `$GUN` / Off The Grid market-reaction analytics.
- Inspect before editing and preserve unrelated behavior.
- Never expose or commit secrets; use environment variables and never commit `.env`.
- Use limited live Nansen API calls and prefer fixtures for development and tests.
- Test meaningful changes and keep documentation synchronized.
- Keep commits small and auditable; update DEV reports for meaningful stages.
- Do not modify production OTG systems without explicit task authorization.
- Do not invent API behavior, schemas, contract addresses, or external facts; verify before implementation.
